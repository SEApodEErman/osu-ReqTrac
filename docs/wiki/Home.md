# osu!ReqTrac Wiki

osu!ReqTrac keeps track of hitsound, guest difficulty, storyboard, and other osu! mapping requests.

## For users

- [Getting started](https://github.com/SEApodEErman/osu-ReqTrac/wiki/Getting-started): installation and osu! API setup.
- [Using ReqTrac](https://github.com/SEApodEErman/osu-ReqTrac/wiki/Using-ReqTrac): requests, categories, imports, search, and shortcuts.
- [Google Sheets](https://github.com/SEApodEErman/osu-ReqTrac/wiki/Google-Sheets): importing a public sheet and publishing your request list.
- [Data and backups](https://github.com/SEApodEErman/osu-ReqTrac/wiki/Data-and-backups): storage locations, restore behavior, and privacy.

## For developers

- [Development](https://github.com/SEApodEErman/osu-ReqTrac/wiki/Development): local setup, configuration, architecture, tests, and contributions.
- [Releasing](https://github.com/SEApodEErman/osu-ReqTrac/wiki/Releasing): versioning, CI packaging, and publishing installers.
- [Credits and notices](https://github.com/SEApodEErman/osu-ReqTrac/wiki/Credits-and-notices): tools, license, and third-party notices.
